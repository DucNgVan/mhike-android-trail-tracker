# M-Hike Coursework README

## Overview

M-Hike is a mobile application for hikers.

## Core Features

1.  Enter Hike Details
2.  Manage Hikes (SQLite CRUD)
3.  Manage Observations
4.  Search Hikes
5.  Cross-platform Prototype
6.  Cross-platform Persistence
7.  Additional Features

-   Android app

-   Report
